policy_key: R2.order.create.metal
title: 钣金订单创建规则
version: 2026-09-29.1
---
1. 客户匹配：订单客户必须与 ERP 客户主数据唯一匹配；多个候选时询问确认，不猜测客户。
2. 客户价格与价格类型（按客户主数据固定口径，不查历史订单推断）：单价 unit_price、价格类型 price_type 直接按该客户 ERP 主数据（customers）采用——用户明确提供时以用户为准；主数据单价为 0 视为未定价（0 不是真实单价，不得采用），须询问客户确认（用户显式提供的 0 是合法免费价，可以写入）；价格类型经由主数据确认，主数据缺失时才询问。
3. 重量单位：计价单位只有 kg 或 m² 两种，须唯一确定（默认按客户主数据计价单位换算；用户明确给定时以用户为准）；按该客户主数据计价单位 price_unit 换算——"元/kg"→kg、"元/平方"→m²（主数据 price_unit 必有枚举值，直接换算即可，不查历史订单推断）；主数据缺失或取值异常无法换算时才询问确认，不默认单位。
4. 计价口径：总金额（total_amount，由 ERP 计算）= 数量 × 每单位重量 × 单价 + 附加款 surcharge_amount（附加款为 0 或未填时即基础金额）。
5. 重量 0：缺重量时填数字 0，0 仅表示待补充（不参与计价），不视为实际重量；禁止填写文字或非数字占位（如"未知""待定"），字段类型是数字。
6. 创建日期默认当天，用户要求时可回溯到过去日期。
7. 未完成：创建订单时 status 固定填'未完成'（订单创建后即为未完成状态），禁止填写'草稿'、'完成'等其他取值，不要询问用户状态。
8. 附加款：用户要求加收额外费用（如打磨费）时填写 surcharge_amount 附加款（元，数字）；可选——用户未提及时省略该字段（ERP 默认 0.00）；必须 ≥0 且最多 2 位小数；塑粉订单没有附加款，禁止填写。
9. 同轮多条一次调用：同一轮要创建多个钣金订单时，把所有明细放进 items 列表一次调用本工具（每条明细 = 一条订单），系统只出一张确认卡，点一次确认即批量写入；一张卡最多 20 条，且一张卡不得混装钣金与塑粉（order_type 恒在顶层）；禁止把同轮多条拆成多次调用。**超限（>20 条）例外**：不得自行删减条目、也不得只提交前 20 条；必须先向用户说明实际条数，并询问是否分批确认（分两张卡，例如先确认前 20 条、用户同意后再出余下）。
10. 部分失败与补写：批量写入时单条明细失败不中断其余条目；未完成项可再次发起同一工具补齐（已成功项自动跳过），已写入的不重复写。
