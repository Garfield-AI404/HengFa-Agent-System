---
policy_key: R3.order.update.powder
title: 塑粉订单更新规则
version: 2026-09-29.1
---
1. 塑粉字段白名单：只能更新白名单内字段（色号、重量、价格、备注等塑粉口径字段）。
2. 重量和价格规则：重量必须大于 0；价格用户明确给价时以用户为准，未给价时按该供货商加色号的历史价格口径核对，无历史价或存在多个不同价格时询问确认。
3. 写前查询：更新前必须先查询当前订单记录。
4. expected_updated_at：更新携带期望的当前版本时间戳；冲突时拒绝并要求重读。
5. 同轮多条一次调用：同一轮要修改多个塑粉订单时，把所有明细放进 items 列表一次调用本工具（每条明细 = 目标订单 ID + 期望变化字段），系统只出一张确认卡，点一次确认即批量更新；一张卡最多 20 条，同一张卡内订单 ID 不得重复，且一张卡不得混装钣金与塑粉（order_type 恒在顶层）；禁止把同轮多条拆成多次调用。**超限（>20 条）例外**：不得自行删减条目、也不得只提交前 20 条；必须先向用户说明实际条数，并询问是否分批确认（分两张卡，例如先确认前 20 条、用户同意后再出余下）。
6. 部分失败与补写：批量更新时单条明细失败不中断其余条目；未完成项可再次发起同一工具补齐（已成功项自动跳过）。
