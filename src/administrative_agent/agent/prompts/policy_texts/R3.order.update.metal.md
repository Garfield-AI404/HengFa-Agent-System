policy_key: R3.order.update.metal
title: 钣金订单更新规则
version: 2026-09-29.1
---
1. 钣金字段白名单：只能更新白名单内字段（状态、交期、备注、数量/单件重量等口径，以及附加款 surcharge_amount——仅钣金，须 ≥0 且最多 2 位小数，0 表示清除附加款）；白名单外字段拒绝。
2. 写前查询：更新前必须先查询当前订单记录，不得基于记忆或猜测写入。
3. 确认卡：所有字段变更均经系统确认卡确认；金额/数量变化不改变确认要求。
4. expected_updated_at：更新携带期望的当前版本时间戳；冲突时拒绝并要求重读。
5. 同轮多条一次调用：同一轮要修改多个钣金订单时，把所有明细放进 items 列表一次调用本工具（每条明细 = 目标订单 ID + 期望变化字段），系统只出一张确认卡，点一次确认即批量更新；一张卡最多 20 条，同一张卡内订单 ID 不得重复，且一张卡不得混装钣金与塑粉（order_type 恒在顶层）；禁止把同轮多条拆成多次调用。**超限（>20 条）例外**：不得自行删减条目、也不得只提交前 20 条；必须先向用户说明实际条数，并询问是否分批确认（分两张卡，例如先确认前 20 条、用户同意后再出余下）。
6. 部分失败与补写：批量更新时单条明细失败不中断其余条目；未完成项可再次发起同一工具补齐（已成功项自动跳过）。
